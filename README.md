# Умный дом

Учебная симуляция на HTML, CSS и JavaScript. Откройте `index.html` в браузере. Состояние и журнал сбрасываются при перезагрузке.

На вкладке «Управление» можно переключать два светильника и задавать температуру одной зоны. Климатическая установка сама выбирает нагрев или охлаждение. Камера показывает, есть ли человек у входа.

Раз в 8 секунд симулятор может переключить свет, изменить показание датчика или имитировать появление либо уход человека. Галочка «Случайные события» останавливает случайные изменения. Климатическая установка продолжает доводить температуру до заданного значения.

В «Журнале» видно время и источник изменений света и температуры. Для камеры журнал хранит одну запись на обнаружение: время начала и окончания либо отметку «сейчас».

Вся логика в `app.js`. **Команда** оформляет переключение света и изменение заданной температуры отдельными объектами с методом `execute()`. **Наблюдатель** уведомляет журнал и климатическую установку через `update(event)`.
